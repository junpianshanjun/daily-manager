# コマンドRPG ― ステップ1

ブラウザ（PC・スマホ両対応）で遊べる2DコマンドRPG。ステップ1ではコアループと演出の土台を実装。

## ファイル構成

```
command-rpg/
  index.html          画面（タイトル／フィールド／バトル／仮想パッド）
  style.css           黒背景＋白二重線のクラシックRPG風UI
  data/               ★データはすべてここに分離（ロジックに直書きしない）
    characters.json   主人公の初期値・成長率・ポーション・ダメージ計算式の係数・ドット絵
    enemies.json      敵のステータス・出現エリア・ドット絵（ボス含む）
    skills.json       スキル（MP・倍率・解放レベル）
    map.json          20×20マップ・タイル定義（通行可否・エンカウント率・色）
  js/
    audio.js          Web Audio APIのレトロ風シンセSE（ミュート対応）
    battle.js         ターン制コマンドバトルと演出（点滅・シェイク・ポップアップ・会心）
    game.js           フィールド移動・タイトル・セーブ・メッセージ表示・入力統合
```

## ダメージ計算式

- 通常攻撃： `floor((ATK×2 − DEF) × 乱数0.85〜1.15 × 会心倍率)`、最低1
- 会心（クリティカル）： 確率12%、ダメージ1.6倍、専用SE＋シェイク＋表示
- スキル攻撃： `floor((ATK×スキル倍率 − DEF) × 乱数0.9〜1.1)`、最低1
- ぼうぎょ中： 被ダメージ0.5倍

## ステータス設計

- 主人公初期値： HP32 / MP10 / ATK11 / DEF5 / SPD7、やくそう3個
- レベルアップ成長： HP+8 / MP+3 / ATK+3 / DEF+2 / SPD+1
- 次レベル必要経験値： `20 + (Lv−1)×15`
- スキル解放： かえんぎり Lv1 / いやしのひかり Lv2 / しっぷうづき Lv4

## 操作

- キーボード： 矢印/WASD＝移動・選択、Enter/Z＝決定、Esc/X＝戻る、M＝音ON/OFF
- スマホ： 画面下の仮想ゲームパッド（十字キー＋A/Bボタン）、コマンドはタップも可

## セーブ

localStorage に保存。戦闘勝利・レベルアップ・泉回復でオートセーブ、「セーブ」ボタンで手動セーブ。タイトルの「コンティニュー」から再開。
