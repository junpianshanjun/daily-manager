# コマンドRPG ― ステップ2

ブラウザ（PC・スマホ両対応）で遊べる2DコマンドRPG。
ステップ1（コアループ＋演出）に、ステップ2で街・NPC・ショップ・装備・敵AI・状態異常・スマホUXを追加。

## ファイル構成

```
command-rpg/
  index.html / style.css   画面とUI（黒背景＋白二重線、100dvh、モーダルシート）
  data/                    ★データはすべてここに分離
    characters.json  主人公・成長率・計算式の係数・ドット絵
    enemies.json     敵（行動パターン付き）・ドット絵
    skills.json      スキル（属性・倍率・会心率・解放レベル）
    map.json         フィールド20×20（街入口タイル追加）
    town.json        街マップ20×20（ショップ/宿屋/井戸/出口）
    npcs.json        NPC配置と会話（ヒント）
    items.json       武器・防具・消耗品・ショップ在庫・売却率
  js/
    audio.js   Web AudioシンセSE（ミュート対応）
    battle.js  コマンドバトル＋演出＋敵AI＋状態異常
    game.js    フィールド/街・会話・メニュー・装備・ショップ・確認ダイアログ・セーブ
```

## ステップ2の追加仕様

- 街：スタート地点の北から入れる。NPC3人（長老＝ボス/溜め攻撃のヒント、僧侶＝毒/デバフのヒント、村人＝施設案内）、宿屋（10Gで全回復、確認ダイアログ付き）、ショップ（購入/売却とも確認ダイアログ付き、売却は定価の50%）
- メニュー（ボタン/Bキー/タップ）：ステータス確認、装備変更（攻撃/防御の増減プレビュー表示→即時反映）、アイテム使用（確認付き）、セーブ（上書き確認付き）
- 敵AI：スライム＝通常、ゴブリン＝防御デバフ、オオグモ＝毒（毎ターン4ダメ×3ターン、どくけしで治療）、オオカミ＝力を溜める→次ターン大ダメージ（ぼうぎょで半減）、魔王＝溜め＋デバフ＋暗黒の一撃の混合
- スキル：かえんぎり（炎・高火力）/ いやしのひかり（光・回復）/ しっぷうづき（風・高会心率）
- ガイド行：画面上部に現在の目標を1行表示（街の中では施設案内に切替）
- 全滅時：街の宿屋で復帰（HP半分回復、所持金半分を失う）。進行不能にならない
- スマホUX：リスト行は最小52px、パネル内スクロール（最大78dvhのボトムシート）、仮想パッドは常時表示、購入/売却/アイテム使用/セーブ上書きは2段階確認
- セーブ互換：ステップ1のセーブデータ（同じキー）は装備・所持品を初期値で補完してそのまま継続可能

## ダメージ計算式・ステータス

- 通常攻撃： floor((実効ATK×2 − 実効DEF) × 乱数0.85〜1.15 × 会心倍率)、最低1。実効ATK＝素の攻撃力＋武器ボーナス、実効DEF＝素の防御力＋防具ボーナス−デバフ
- 会心： 12%（しっぷうづきは50%）、1.6倍
- レベルアップ成長： HP+8 / MP+3 / ATK+3 / DEF+2 / SPD+1、必要経験値 20+(Lv−1)×15

## 操作

- キーボード： 矢印/WASD＝移動・選択、Enter/Z＝決定・話しかけ、Esc/X＝戻る・メニュー開閉、M＝音ON/OFF
- スマホ： 仮想パッド（十字＋A/B）、NPCや建物はタップでも話しかけ/利用可、コマンド・リストは直接タップ可

## クレジット（CC0素材）

- キャラクターイラスト「ハチ」： HachiStudio（OpenGameArt "Character Imageset" / "Character Images"、ライセンス CC0）。タイトル画面、看板娘ハチの会話ポートレート、ショップ画面に使用。画像は `js/assets.js` にBase64埋め込み（GitHubへのテキスト保存形式に合わせるため）。CC0のためクレジット表記は必須ではないが、感謝を込めて記載する。
- ちび版・モンスター素材（同作者のCC0素材）は画風の統一のため今回は不採用。

## ボイス（ステップ2.5で追加）

- NPCの会話と魔王の登場セリフにキャラボイスを実装。方式は2層：
  1. ブラウザの音声合成（SpeechSynthesis、ja-JP）でセリフを実際に読み上げ。キャラごとに声の高さ（pitch）と速さ（rate）を変更（ハチ＝高め、長老＝低め、魔王＝最低など）
  2. 音声合成が使えない環境でも鳴る、文字送りに合わせたキャラ別ピッチのボイス音（Web Audio）
- 「ボイス」ボタンでON/OFF切替（設定は保存される）。声の割り当ては `data/npcs.json` の `voiceKey`、声質パラメータは `js/game.js` の `VOICES` で管理。
