# Daily Manager

自分専用の生活管理Webアプリです。HTML / CSS / JavaScriptだけで動き、外部APIや有料サービスは使いません。

## できること

- タスクの追加・削除・完了チェック
- 習慣の追加・削除、今日できたかのチェック
- 習慣の継続日数（○日連続）の表示
- 今日の達成率の表示（タスク＋習慣）
- データはブラウザの `localStorage` に自動保存

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | 見た目（スマホ向け） |
| `script.js` | 動きと保存の仕組み |
| `README.md` | この説明書 |

## スマホで開く方法（GitHub Pages）

1. このリポジトリの **Settings** → **Pages** を開く
2. Branch で **main** と **/ (root)** を選んで **Save**
3. 1〜2分待つと公開アドレスが表示される
   例：`https://junpianshanjun.github.io/daily-manager/`
4. AndroidのChromeでそのアドレスを開く
5. Chromeのメニューから **ホーム画面に追加** すると、アプリのように使える

## 注意

- データは「開いたブラウザの中」にだけ保存されます。別のブラウザで開くとデータは別々になります。
- ブラウザのデータを消去すると、タスクと習慣も消えます。
- インターネットにデータを送ることはありません。
